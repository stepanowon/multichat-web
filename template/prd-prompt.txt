강사와 수강생 간 소스 코드를 공유하고 메시지, 파일을 다운로드 받을 수 있는 웹기반 메시징 시스템을 개발한다.를 주고 받을 수 있는 개발한다.
다음 요구사항을 만족시켜야 한다.

1. 화면 디자인 
- 화면 디자인은 @template/index.html의 스타일을 적용해봐.

2. 초기 화면에서 강사와 수강생으로 나눠서 채팅 화면에 진입할 수 있도록 한다.
- 관리자는 초기화면에서 관리자 패스워드를 입력한다.
  * 관리자 패스워드와 수강생들의 공통 패스워드는 서버 구동 시 환경변수로 지정한다(앱 내부에서 별도로 설정/저장하지 않음).

  - 사용자는 초기화면에서 이름(닉네임), 고유식별자, 패스워드로 접속한다.  사용자 정보는 애플리케이션 내부에 저장하지 않도록 한다.
   * 이미 접속한 사용자 중에 고유식별자가 충돌나는 사용자가 있다면 다시 입력을 요구하도록 개발한다.

3. 관리자는 사용자(수강생)들에게 파일을 공유할 수 있도록 기능을 제공한다.
- 관리자(강사)는 웹 애플리케이션이 실행중인 서버상의 디렉토리를 지정할 수 있어야 한다.
- 지정된 디렉토리의 파일들을 수강생들은 채팅화면에서 다운로드 받을 수 있어야 한다.
  * 하위 디렉토리의 파일들도 수강생들이 다운로드 받을 수 있어야 한다.

4. 채팅 화면에서에서 제공해야할 기능
- 관리자는 채팅 화면에서 접속한 사용자 목록을 볼수 있어야 한다.
- 관리자는 채팅 화면에서 모든 사용자 또는 특정 사용자에게 메시지를 보낼 수 있어야 한다.
- 수강생은 채팅 화면에서 메시지 보낼 대상을 "전체 사용자" 또는 "강사"(강사에게만, 다른 수강생에겐 안 보임) 중 선택할 수 있어야 한다. 기본값은 전체 사용자.
- 대화입력창은 여러 줄(멀티라인) 입력이 가능해야 한다. Shift+Enter는 줄바꿈, Enter는 전송으로 한다.
- 대화입력창에서 클립보드로 복사한 이미지를 전송할 수 있어야 한다(화면 어디에 포커스가 있어도 Ctrl+V로 인식).
- 대화입력창에서 파일을 드래그앤드롭하여 전송할 수 있어야 한다(채팅 영역 어디에 놓아도 인식). 이미지·파일 첨부는 10MB까지만 허용한다.
- 채팅 화면에서 메시지를 마우스 우클릭하면 클립보드로 메시지가 복사될 수 있는 컨텍스트 메뉴가 나타나도록 한다.
- 강사나 수강생은 자신이 전송한 메시지를 삭제할 수 있어야 하고, 삭제 시 모든 접속자 화면과 서버 저장소(로그·첨부파일)에서도 함께 제거되어야 한다. 메시지 우클릭 컨텍스트 메뉴에서 삭제할 수 있도록 한다.
- 채팅창에 업로드된 이미지(특히 클립보드로 붙여넣은 이미지)를 클릭하면 CSS 레이어로 원본을 확대해서 보여주고, 이미지를 우클릭하면 다운로드할 수 있는 컨텍스트 메뉴가 나타나야 한다.
- 채팅 화면의 대화는 날짜단위로 구분되어 보여야 한다. 이를 위해서 채팅화면에 날짜를 선택할 수 있는 기능이 나타나야 한다.
  * 날짜 선택기능은 DropDown 형태로 보여지도록 한다.
- 채팅 대화 내용이 많아지면 대화창은 항상 가장 아래로 자동 스크롤되어야 한다.

5. 사용자는 대화창에 있는 날짜별 모든 대화 내용을 Markdown 형식으로 다운로드할 수 있어야 한다.
- 이를 위해 메시지는 애플리케이션이 실행중인 서버에 파일로 저장되어야 한다.
- 대화 내용을 중 이미지는 별도로 메시지를 저장하는 폴더 아래에 하위 폴더를 만들어 저장한다.
- 업로드한 파일에 원래 파일명이 있는 경우, 저장/다운로드 시 파일명 뒤에 해시값을 붙인 형태로 저장한다(예: test.js → test.xxxxxxx.js).

6. 기타
- 사용자가 접속할 때 사용자들의 대화 창에는 아무런 메시지도 나타나지 않도록 해.
  * 강사의 대화 창에는 수강생들의 목록이 갱신되고, 메시지가 나타나도록 한다.
- 수강생들의 화면에는 수강생 목록 대신 파일을 다운로드받을 수 있는 목록화면이 나타나야 해.
- 강사 화면에는 수강생들이 접속할 때 필요한 서버 주소(LAN IP)를 안내해줘야 한다.

7. 기술 스택
- 사용자 화면(프론트엔드)은 React로 개발한다.
- 서버(백엔드)는 Node.js + Express 기반으로 개발한다.
- 인증은 JWT(JSON Web Token)를 사용한다. 로그인 성공 시 서버가 JWT를 발급하고, 이후 REST/WebSocket 요청은 이 토큰으로 인증한다.
- 관리자 패스워드는 환경변수 `ADMIN_PASSWORD`, 수강생 공통 패스워드는 환경변수 `STUDENT_PASSWORD`로 설정한다.
