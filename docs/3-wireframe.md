# MultiChat Web 화면 설계

**버전:** 1.1
**작성일:** 2026-08-09
**최종 수정:** 2026-11-17 (상단 바 설문·나가기 버튼, 입퇴장 토스트, 강사 삭제 권한, S5 설문 화면 추가)
**관련 문서:** [1-prd.md](./1-prd.md), [2-stack.md](./2-stack.md)
**대상:** Desktop 전용 (반응형/모바일 미고려)

## 화면 목록

| # | 화면 | 접근 |
|---|---|---|
| S1 | 진입 화면 (역할 선택 + 로그인) | 강사/수강생 공통 |
| S2 | 관리자(강사) 채팅 화면 | 관리자 |
| S3 | 수강생 채팅 화면 | 수강생 |
| S4 | 공유 디렉토리 지정 모달 (관리자) | 관리자 |
| S5 | 설문 패널 (목록 / 작성 / 응답·결과) | 강사·수강생 공통(작성·마감·삭제는 관리자) |

관리자/수강생 패스워드는 서버 구동 전 환경변수(`ADMIN_PASSWORD`, `STUDENT_PASSWORD`)로 지정하므로 앱 내 초기 설정 화면 없음.

디자인 톤은 `template/index.html` 계승: 다크 그라데이션 배경(`#0f172a → #1e293b → #312e81`) + 화이트 카드(`--card:#fff`, `border-radius:18px`, `box-shadow`) + 인디고/시안 그라데이션 버튼(`--accent:#4f46e5 → --accent2:#06b6d4`).

## S1. 진입 화면 (역할 선택 + 로그인)

```
┌──────────────────────────────────────────────┐
│                                                │
│           [badge] 1일차 실습 채팅방              │
│              MultiChat Web                    │
│      강사·수강생 실시간 메시지 & 파일 공유          │
│                                                │
│   ┌───────────────┐   ┌───────────────┐      │
│   │   👨‍🏫 강사     │   │   🧑‍🎓 수강생   │      │
│   │  로 입장       │   │   로 입장      │      │
│   │               │   │               │      │
│   │ 관리자 패스워드 │   │ 닉네임  [___] │      │
│   │ [__________]  │   │ 고유식별자[___]│      │
│   │               │   │ 공통 패스워드[_]│      │
│   │ [ 입장하기 ]   │   │ [ 입장하기 ]   │      │
│   └───────────────┘   └───────────────┘      │
│                                                │
│   ※ 오류 메시지 영역 (패스워드 불일치 /            │
│      식별자 중복 시 카드 하단 빨간 텍스트)          │
└──────────────────────────────────────────────┘
```

- `template`의 `.grid` 2-카드 레이아웃 재사용(강사 카드 / 수강생 카드 좌우 배치).
- 수강생 카드: 닉네임, 고유식별자, 공통 패스워드 3개 입력.
- 실패 케이스:
  - 패스워드 불일치 → 카드 내 인라인 에러.
  - 고유식별자 충돌(이미 접속 중) → "이미 사용 중인 식별자입니다" 에러, 입력창 포커스, 재입력 유도(화면 전환 없음).
  - 닉네임/식별자가 trim 후 "강사"와 완전히 일치 → 예약된 이름이라는 에러("보조강사" 등은 허용).
  - 빈 칸이 있으면 에러.
  - (현재 구현) 빈 칸·예약된 이름은 서버가 사유 코드를 주지만 화면에는 "로그인 실패"로만 표시된다 — 사유별 문구로 바꾸는 것이 개선 과제.
- 입장 성공 시 역할에 따라 S2(관리자) 또는 S3(수강생)로 이동.

## S2. 관리자(강사) 채팅 화면

```
┌───────────────────────────────────────────────────────────┐
│ MultiChat · 강사 모드  [설문 (2)] [날짜 ▾ 2026-08-09] [MD 다운로드] [나가기]│
├───────────────────┬─────────────────────────────────────────┤
│ 수강생 접속 주소    │       ┌──────────────────────┐            │
│ http://172.30.1.29 │       │ 홍길동님이 입장했습니다 │ ← 토스트(3초)│
│  :5000        [⧉]  │       └──────────────────────┘            │
│                    │  홍길동 10:03                            │
│ 접속자 (12)        │   질문 있습니다 소켓 연결이...            │
│ ┌───────────────┐ │  나(강사) 10:04                          │
│ │● 홍길동    [✕]│ │   네 말씀하세요                           │
│ │● 김민수    [✕]│ │                                          │
│ │● 이영희    [✕]│ │                                          │
│ │   ...          │ │                                          │
│ └───────────────┘ │                                          │
│ 받는 사람          │                                          │
│ [ 홍길동        ▾]  │                                          │
│                    │                                          │
│ [공유 폴더 지정]     │                                          │
├───────────────────┴─────────────────────────────────────────┤
│ [+]  [메시지 입력(3줄, Shift+Enter 줄바꿈)________]  [ 전송 ]   │
│  (클립보드 이미지 붙여넣기 / 화면 어디든 드래그앤드롭 가능)          │
└───────────────────────────────────────────────────────────┘
```

- 좌측 사이드 패널: **수강생 접속 주소**(서버 LAN IP, 복사 버튼) + 접속자 목록(실시간 갱신, 온라인 점 표시, 각 항목에 연결 강제 종료 `✕` 버튼) + 받는 사람 선택(전체/특정 사용자 드롭다운) + "공유 폴더 지정" 버튼(S4 모달 오픈).
- 접속자 목록의 `✕` 클릭 → 확인창(`해당 수강생의 연결을 강제로 종료하시겠습니까?`) → 확인 시 해당 수강생 WebSocket 강제 종료, 접속자 목록에서 즉시 제거. 종료된 수강생은 세션이 완전히 삭제되어 로그인 화면으로 이동, 재접속하려면 재로그인 필요.
- 받는 사람 드롭다운에서 고른 수강생이 퇴장·강제 종료로 목록에서 사라지면 "전체"로 자동 복귀.
- 우측: 대화 영역. 새 메시지 도착 시 자동으로 맨 아래로 스크롤. 1:1 메시지는 발신 정보 옆에 `(나에게)` 등으로 대상 표시.
- 입퇴장 알림: 대화 영역에 쌓지 않고 화면 상단 중앙 토스트로 3초간 표시(강사 화면에만).
- 상단바: `설문 (N)` 버튼(S5 오픈, N은 등록된 설문 수), 날짜 드롭다운(대화 있는 날짜만 목록), 선택 날짜 Markdown 다운로드, 나가기.
- 메시지 우클릭 → 컨텍스트 메뉴: 텍스트는 `복사하기`, 이미지는 `이미지 다운로드`, 삭제는 `삭제하기`(빨간색) — 강사는 모든 메시지에 삭제 항목이 붙는다.
- 이미지 메시지 클릭 → 전체화면 라이트박스로 확대.
- 입력창: `＋`(파일 선택) + 여러 줄 텍스트(Enter 전송/Shift+Enter 줄바꿈) + 클립보드 이미지 붙여넣기(화면 어디서든) + 드래그앤드롭 파일(대화 영역 어디든) + 전송 버튼. 첨부는 세 경로 모두 10MB 제한. 받는 사람 드롭다운 선택값에 따라 전체 브로드캐스트/1:1 전송 분기.

## S3. 수강생 채팅 화면

```
┌───────────────────────────────────────────────────────────┐
│ MultiChat · 홍길동   [설문 ①] [날짜 ▾ 2026-08-09] [MD 다운로드] [나가기]│
├───────────────────┬─────────────────────────────────────────┤
│ 공유 파일          │  (입장 시 시스템 메시지 없음 — 빈 상태로 시작)  │
│ ┌───────────────┐ │                                          │
│ │ 📁 chapter1/   │ │  강사 10:04                              │
│ │  📄 index.html │ │   네 말씀하세요                           │
│ │  📄 style.css  │ │                                          │
│ │ 📁 chapter2/   │ │  홍길동(나) 10:05                        │
│ │  📄 app.js     │ │   감사합니다!                             │
│ └───────────────┘ │                                          │
│ 받는 사람          │                                          │
│ ( ) 강사           │                                          │
│ (•) 전체 사용자      │                                          │
├───────────────────┴─────────────────────────────────────────┤
│ [+]  [메시지 입력(3줄, Shift+Enter 줄바꿈)________]  [ 전송 ]   │
│  (클립보드 이미지 붙여넣기 / 화면 어디든 드래그앤드롭 가능)          │
└───────────────────────────────────────────────────────────┘
```

- 좌측 사이드 패널: 사용자 목록 대신 공유 디렉토리 파일 트리(하위 폴더 포함, 클릭/버튼으로 개별 다운로드) + 받는 사람 선택(강사/전체 사용자, 기본값 강사가 아니라 **전체 사용자**).
- 대화 영역: 본인 메시지 + 강사가 보낸(전체 or 본인 지정) 메시지 + 다른 수강생이 "전체 사용자"로 보낸 메시지 표시. 입퇴장 시스템 메시지 없음.
- 상단바 `설문` 버튼의 숫자 배지(①)는 아직 응답하지 않은 진행 중 설문 수. 0이면 배지 없음.
- 컨텍스트 메뉴의 `삭제하기`는 본인 메시지에만 표시.
- 상단바/입력창/컨텍스트 메뉴/날짜 드롭다운/라이트박스는 S2와 동일 컴포넌트 재사용(사이드 패널·상단바 버튼만 다름).

## S4. 공유 디렉토리 지정 모달 (관리자)

```
┌───────────────────────────────────┐
│  공유 디렉토리 지정            [x] │
│                                    │
│  서버 경로: [ /srv/course/day1___ ]│
│  현재 지정: /srv/course/day1       │
│                                    │
│  [ 지정하기 ]                      │
└───────────────────────────────────┘
```

- 서버 파일시스템 절대경로 텍스트 입력(브라우저는 로컬 경로 접근 불가하므로 파일 탐색 UI 없이 경로 직접 입력).
- 지정 즉시 모든 수강생 S3 좌측 파일 목록이 갱신(WebSocket 브로드캐스트).
- 잘못된 경로/존재하지 않는 디렉토리 입력 시 인라인 에러.

## S5. 설문 패널 (강사·수강생 공통 모달)

상단바 `설문` 버튼으로 여는 모달. 안에서 목록 → 작성(강사) / 상세(응답·결과)로 전환한다.

**목록**
```
┌─────────────────────────────────────────┐
│  설문                                [✕] │
│  [＋ 새 설문 만들기]          ← 강사만     │
│  ┌─────────────────────────────────────┐│
│  │ 1일차 만족도  [미응답]      진행 중   ││ ← 수강생: 미응답/응답함 태그
│  │ 질문 3 · 응답 12명 · 11/17 09:30    ││
│  ├─────────────────────────────────────┤│
│  │ 사전 설문                    마감     ││
│  └─────────────────────────────────────┘│
│  (없으면 "등록된 설문이 없습니다.")        │
└─────────────────────────────────────────┘
```

**작성 (강사)**
```
┌─────────────────────────────────────────┐
│  설문 제목 [예: 1일차 강의 만족도______]   │
│  ┌ Q1 [다지선다 ▾]            [▲][▼][✕]┐│
│  │ [질문 내용______________________]     ││
│  │ 1. [선택지 1____] [✕]                 ││
│  │ 2. [선택지 2____] [✕]                 ││
│  │ ＋ 선택지 추가     [ ] 복수 선택 허용   ││
│  └──────────────────────────────────────┘│
│  ┌ Q2 [단답형 ▾]              [▲][▼][✕]┐│
│  │ [질문 내용______________________]     ││
│  └──────────────────────────────────────┘│
│  [＋ 다지선다 질문] [＋ 단답형 질문]        │
│  (검증 오류 인라인 표시)                   │
│                         [취소] [설문 등록] │
└─────────────────────────────────────────┘
```

**상세 (응답 + 결과)**
```
┌─────────────────────────────────────────┐
│  ← 목록                          진행 중  │
│  1일차 만족도                              │
│  응답 12명                                │
│  [마감하기] [삭제] [결과 MD 다운로드]       │ ← 마감/삭제는 강사만
│                                          │
│  ─ 응답하기 / 내 응답(수정 가능) ─  ← 수강생│
│  Q1. 오늘 수업은?                          │
│   (•) 좋음  ( ) 보통  ( ) 아쉬움            │
│  Q2. 한마디                                │
│   [답변 입력__________________]            │
│                     [제출 / 응답 수정]     │
│                                          │
│  ─ 결과 (수강생은 "결과 (익명)") ─         │
│  Q1. 오늘 수업은?                          │
│   좋음 [내 선택]          8명 · 67%        │
│   ██████████████░░░░░░                    │
│   홍길동, 김민수, ...      ← 강사만 이름     │
│  Q2. 한마디                                │
│   • 홍길동  유익했습니다   ← 수강생은 이름 없이│
└─────────────────────────────────────────┘
```

- 목록은 최신순. 수강생은 각 설문에 `미응답`/`응답함` 태그, 모두에게 `진행 중`/`마감` 상태 표시.
- 작성: 질문마다 유형(다지선다/단답형) 선택, 순서 이동·삭제. 다지선다는 선택지 추가·삭제, 복수 선택 허용 체크. 질문 1~50개, 선택지 2~20개. 저장 시 서버 검증 실패 문구를 폼 하단에 표시.
- 응답: 모든 질문 필수(빠진 질문이 있으면 서버가 "N번 질문의 답을 선택하세요." 같은 문구로 거부). 제출 후 "응답을 제출했습니다."(수정 시 "응답을 수정했습니다.") 표시, 마감 전까지 `응답 수정` 가능. 마감된 설문에 응답하지 않았으면 "마감된 설문이라 응답할 수 없습니다."
- 결과: 다지선다는 선택지별 막대(인원·비율, 본인 선택은 `내 선택` 태그), 단답형은 답변 목록. 강사 화면에만 응답자 이름 표시.
- 다른 사람이 응답하거나 강사가 마감·삭제하면 열려 있는 목록·상세가 바로 갱신. 삭제는 확인창 후 실행.
- `결과 MD 다운로드`: 화면 결과와 같은 규칙(강사만 이름 포함)의 Markdown 파일 `설문결과_<제목>.md`.

## 공통 컴포넌트

- **상단바**(`ChatTopBar`): 로고/역할 표시, 화면별 버튼(설문), 날짜 드롭다운(`<select>`), Markdown 다운로드 버튼, 나가기.
- **대화 영역**(`ChatPane`): 메시지 목록 + 입력창 + 드래그앤드롭 대상. 강사·수강생 화면이 같은 컴포넌트 사용.
- **메시지 버블**: 발신자명 + 시간, 본인 메시지는 우측 정렬 + 인디고 계열, 상대 메시지는 좌측 정렬 + 화이트 카드. 새 메시지/삭제/날짜 전환 시 대화 영역 맨 아래로 자동 스크롤.
- **이미지 메시지**: 버블 내 썸네일, 클릭 시 전체화면 라이트박스(어두운 배경 오버레이)로 원본 확대. 배경이나 X 버튼 클릭 시 닫힘.
- **컨텍스트 메뉴**: 메시지 우클릭 시 커서 위치에 팝업. 텍스트는 `복사하기`, 이미지는 `이미지 다운로드`, 삭제 가능한 메시지(본인 것, 강사는 전부)는 `삭제하기`(빨간 글자) — 메시지 종류/권한에 따라 항목이 조합됨. 바깥 클릭 시 닫힘.
- **드래그앤드롭**: 채팅 영역(사이드바 제외 메인 대화창 전체)이 드롭 대상 — 진입 시 점선 테두리 하이라이트, 그 밖에 떨어뜨려도 브라우저가 파일을 새 탭으로 열지 않도록 차단. 10MB 초과 시 인라인 에러 문구.
- **메시지 입력창**: `<textarea>` 3줄 기본 높이(최대 240px까지 자동 확장), Enter 전송/Shift+Enter 줄바꿈.
