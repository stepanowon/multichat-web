# MultiChat Web 화면 설계

**버전:** 1.0
**작성일:** 2026-08-09
**관련 문서:** [1-prd.md](./1-prd.md), [2-stack.md](./2-stack.md)
**대상:** Desktop 전용 (반응형/모바일 미고려)

---

## 화면 목록

| # | 화면 | 접근 |
|---|---|---|
| S1 | 진입 화면 (역할 선택 + 로그인) | 강사/수강생 공통 |
| S2 | 관리자(강사) 채팅 화면 | 관리자 |
| S3 | 수강생 채팅 화면 | 수강생 |
| S4 | 공유 디렉토리 지정 모달 (관리자) | 관리자 |

관리자/수강생 패스워드는 서버 구동 전 환경변수(`ADMIN_PASSWORD`, `STUDENT_PASSWORD`)로 지정하므로 앱 내 초기 설정 화면 없음.

디자인 톤은 `template/index.html` 계승: 다크 그라데이션 배경(`#0f172a → #1e293b → #312e81`) + 화이트 카드(`--card:#fff`, `border-radius:18px`, `box-shadow`) + 인디고/시안 그라데이션 버튼(`--accent:#4f46e5 → --accent2:#06b6d4`).

## S1. 진입 화면 (역할 선택 + 로그인)

```
┌──────────────────────────────────────────────┐
│                                                │
│           [badge] 1일차 실습 채팅방              │
│              MultiChat Web                    │
│      강사·수강생 실시간 메시지 & 파일 공유          │
│                                                │
│   ┌───────────────┐   ┌───────────────┐      │
│   │   👨‍🏫 강사     │   │   🧑‍🎓 수강생   │      │
│   │  로 입장       │   │   로 입장      │      │
│   │               │   │               │      │
│   │ 관리자 패스워드 │   │ 닉네임  [___] │      │
│   │ [__________]  │   │ 고유식별자[___]│      │
│   │               │   │ 공통 패스워드[_]│      │
│   │ [ 입장하기 ]   │   │ [ 입장하기 ]   │      │
│   └───────────────┘   └───────────────┘      │
│                                                │
│   ※ 오류 메시지 영역 (패스워드 불일치 /            │
│      식별자 중복 시 카드 하단 빨간 텍스트)          │
└──────────────────────────────────────────────┘
```

- `template`의 `.grid` 2-카드 레이아웃 재사용(강사 카드 / 수강생 카드 좌우 배치).
- 수강생 카드: 닉네임, 고유식별자, 공통 패스워드 3개 입력.
- 실패 케이스:
  - 패스워드 불일치 → 카드 내 인라인 에러.
  - 고유식별자 충돌(이미 접속 중) → "이미 사용 중인 식별자입니다" 에러, 입력창 포커스, 재입력 유도(화면 전환 없음).
- 입장 성공 시 역할에 따라 S2(관리자) 또는 S3(수강생)로 이동.

## S2. 관리자(강사) 채팅 화면

```
┌───────────────────────────────────────────────────────────┐
│ MultiChat · 강사 모드            [날짜선택 ▾ 2026-08-09]  [MD 다운로드]│
├───────────────────┬─────────────────────────────────────────┤
│ 수강생 접속 주소    │  ── 2026-08-09 ──                        │
│ http://172.30.1.29 │  [system] 홍길동님이 입장했습니다  10:02   │
│  :5000        [⧉]  │  홍길동 10:03                            │
│                    │   질문 있습니다 소켓 연결이...            │
│ 접속자 (12)        │                                          │
│ ┌───────────────┐ │  나(강사) 10:04                          │
│ │● 홍길동        │ │   네 말씀하세요                           │
│ │● 김민수        │ │  [system] 김민수님이 퇴장했습니다  10:05   │
│ │● 이영희        │ │                                          │
│ │   ...          │ │                                          │
│ └───────────────┘ │                                          │
│ 받는 사람          │                                          │
│ ( ) 전체            │                                          │
│ (•) 홍길동          │                                          │
│                    │                                          │
│ [공유 폴더 지정]     │                                          │
├───────────────────┴─────────────────────────────────────────┤
│ [+]  [메시지 입력(3줄, Shift+Enter 줄바꿈)________]  [ 전송 ]   │
│  (클립보드 이미지 붙여넣기 / 화면 어디든 드래그앤드롭 가능)          │
└───────────────────────────────────────────────────────────┘
```

- 좌측 사이드 패널: **수강생 접속 주소**(서버 LAN IP, 복사 버튼) + 접속자 목록(실시간 갱신, 온라인 점 표시) + 받는 사람 선택(전체/특정 사용자 라디오) + "공유 폴더 지정" 버튼(S4 모달 오픈).
- 우측: 대화 영역. 시스템 메시지(입퇴장)는 강사 화면에만 표시. 새 메시지 도착 시 자동으로 맨 아래로 스크롤.
- 상단바: 날짜 드롭다운(대화 있는 날짜만 목록), 선택 날짜 Markdown 다운로드 버튼.
- 메시지 우클릭 → 컨텍스트 메뉴: 텍스트는 `복사하기`, 이미지는 `이미지 다운로드`, 본인 메시지는 `삭제하기`(빨간색) 조합 표시.
- 이미지 메시지 클릭 → 전체화면 라이트박스로 확대.
- 입력창: 여러 줄 텍스트(Enter 전송/Shift+Enter 줄바꿈) + 클립보드 이미지 붙여넣기(화면 어디서든) + 드래그앤드롭 파일(대화 영역 어디든, 10MB 제한) + 전송 버튼. 받는 사람 라디오에 따라 전체 브로드캐스트/1:1 전송 분기.

## S3. 수강생 채팅 화면

```
┌───────────────────────────────────────────────────────────┐
│ MultiChat · 홍길동            [날짜선택 ▾ 2026-08-09]  [MD 다운로드] │
├───────────────────┬─────────────────────────────────────────┤
│ 공유 파일          │  (입장 시 시스템 메시지 없음 — 빈 상태로 시작)  │
│ ┌───────────────┐ │                                          │
│ │ 📁 chapter1/   │ │  강사 10:04                              │
│ │  📄 index.html │ │   네 말씀하세요                           │
│ │  📄 style.css  │ │                                          │
│ │ 📁 chapter2/   │ │  홍길동(나) 10:05                        │
│ │  📄 app.js     │ │   감사합니다!                             │
│ └───────────────┘ │                                          │
│ 받는 사람          │                                          │
│ (•) 강사           │                                          │
│ ( ) 전체 사용자      │                                          │
├───────────────────┴─────────────────────────────────────────┤
│ [+]  [메시지 입력(3줄, Shift+Enter 줄바꿈)________]  [ 전송 ]   │
│  (클립보드 이미지 붙여넣기 / 화면 어디든 드래그앤드롭 가능)          │
└───────────────────────────────────────────────────────────┘
```

- 좌측 사이드 패널: 사용자 목록 대신 공유 디렉토리 파일 트리(하위 폴더 포함, 클릭/버튼으로 개별 다운로드) + 받는 사람 선택(강사/전체 사용자, 기본값 강사가 아니라 **전체 사용자**).
- 대화 영역: 본인 메시지 + 강사가 보낸(전체 or 본인 지정) 메시지 + 다른 수강생이 "전체 사용자"로 보낸 메시지 표시. 입퇴장 시스템 메시지 없음.
- 상단바/입력창/컨텍스트 메뉴/날짜 드롭다운/라이트박스는 S2와 동일 컴포넌트 재사용(사이드 패널만 다름).

## S4. 공유 디렉토리 지정 모달 (관리자)

```
┌───────────────────────────────────┐
│  공유 디렉토리 지정            [x] │
│                                    │
│  서버 경로: [ /srv/course/day1___ ]│
│  현재 지정: /srv/course/day1       │
│                                    │
│  [ 지정하기 ]                      │
└───────────────────────────────────┘
```

- 서버 파일시스템 절대경로 텍스트 입력(브라우저는 로컬 경로 접근 불가하므로 파일 탐색 UI 없이 경로 직접 입력).
- 지정 즉시 모든 수강생 S3 좌측 파일 목록이 갱신(WebSocket 브로드캐스트).
- 잘못된 경로/존재하지 않는 디렉토리 입력 시 인라인 에러.

## 공통 컴포넌트

- **상단바**: 로고/역할 표시, 날짜 드롭다운(`<select>`), Markdown 다운로드 버튼.
- **메시지 버블**: 발신자명 + 시간, 본인 메시지는 우측 정렬 + 인디고 계열, 상대 메시지는 좌측 정렬 + 화이트 카드. 새 메시지/삭제/날짜 전환 시 대화 영역 맨 아래로 자동 스크롤.
- **이미지 메시지**: 버블 내 썸네일, 클릭 시 전체화면 라이트박스(어두운 배경 오버레이)로 원본 확대. 배경이나 X 버튼 클릭 시 닫힘.
- **컨텍스트 메뉴**: 메시지 우클릭 시 커서 위치에 팝업. 텍스트는 `복사하기`, 이미지는 `이미지 다운로드`, 본인 메시지는 `삭제하기`(빨간 글자) — 메시지 종류/소유자에 따라 항목이 조합됨. 바깥 클릭 시 닫힘.
- **드래그앤드롭**: 채팅 영역(사이드바 제외 메인 대화창 전체)이 드롭 대상 — 진입 시 점선 테두리 하이라이트, 그 밖에 떨어뜨려도 브라우저가 파일을 새 탭으로 열지 않도록 차단. 10MB 초과 시 인라인 에러 문구.
- **메시지 입력창**: `<textarea>` 3줄 기본 높이(최대 240px까지 자동 확장), Enter 전송/Shift+Enter 줄바꿈.
