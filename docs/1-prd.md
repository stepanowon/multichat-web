# MultiChat Web PRD

**버전:** 1.0
**작성일:** 2026-08-09

---

## 개요

강사와 수강생이 실시간으로 메시지·파일·소스코드를 주고받는 웹 기반 강의용 메시징 시스템.

## 목적 및 배경

### 해결하려는 문제

강의 중 강사가 소스코드·파일을 수강생에게 빠르게 배포하고, 실시간 질의응답·공지를 주고받을 채널이 없음. 슬랙/카톡 등 외부 도구는 강의 서버 파일 공유, 접속 통제(패스워드), 대화 로그 보관 요구를 충족 못함.

## 타겟 사용자

- **강사(관리자)**: 강의 진행자, 1인. 파일 배포·전체 공지·사용자 관리 권한 필요.
- **수강생**: 강의당 최대 약 30명 동시 접속. 파일 다운로드, 메시지 송수신만 필요.

**페르소나**

강의실에서 노트북으로 접속해 강사가 올린 실습 코드를 받고, 질문을 채팅으로 남기는 수강생.

## 기능 요구사항

### 화면/디자인
- `template/index.html`의 다크 그라데이션 히어로 + 화이트 카드 톤(색상 변수, 카드 그림자, 그라데이션 버튼 스타일)을 채팅 앱 전반 UI에 적용.

### 접속/인증
- 관리자 패스워드와 수강생 공통 패스워드는 서버 구동 전 환경변수(`ADMIN_PASSWORD`, `STUDENT_PASSWORD`)로 지정. 서버는 기동 시 이 값을 로드해 로그인 검증에 사용(앱 내부 UI로 설정/변경하지 않음, 파일 저장 없음).
- 초기 화면에서 강사/수강생 진입 경로 분리.
  - 관리자: 관리자 패스워드 입력 후 진입.
  - 수강생: 이름(닉네임), 고유식별자, 공통 패스워드 입력 후 진입.
- 사용자 정보(닉네임/식별자)는 서버에 영속 저장하지 않음(세션 동안만 메모리 보관).
- 고유식별자가 현재 접속 중인 사용자와 충돌하면 재입력 요구.

### 파일 공유 (관리자 → 수강생)
- 관리자가 서버 내 특정 디렉토리를 공유 대상으로 지정.
- 수강생은 채팅 화면에서 지정 디렉토리(하위 디렉토리 포함) 파일 목록을 보고 다운로드 가능.

### 채팅 화면
- 관리자: 현재 접속 사용자 목록 조회.
- 관리자: 전체 브로드캐스트 또는 특정 사용자 지정 메시지 전송.
- 수강생: 메시지 전송 대상을 "전체 사용자"(모든 접속자) 또는 "강사"(강사에게만, 다른 수강생에게 안 보임) 중 선택. 기본값은 "전체 사용자". 특정 수강생 지정은 불가.
- 대화 입력창은 여러 줄 입력 가능(Shift+Enter 줄바꿈, Enter 전송).
- 클립보드 이미지 붙여넣기로 이미지 전송(포커스 위치 무관하게 화면 어디서 Ctrl+V 해도 인식).
- 채팅 화면 어디에 파일을 드래그앤드롭해도 전송(입력창 밖에 놓아도 인식, 브라우저가 파일을 새 탭으로 여는 것 방지).
- 이미지/파일 첨부는 10MB까지만 전송 가능, 초과 시 전송 거부하고 안내 표시.
- 메시지 우클릭 → 컨텍스트 메뉴: 텍스트는 클립보드 복사, 이미지는 다운로드, 본인이 보낸 메시지는 삭제 추가 제공.
- 본인이 보낸 메시지는 삭제할 수 있고, 삭제 시 모든 접속자 화면 및 서버 저장소(로그·첨부파일)에서도 제거.
- 이미지 메시지 클릭 시 원본을 화면 위 오버레이(라이트박스)로 확대 표시.
- 대화는 날짜 단위로 구분 표시, 화면 상단 드롭다운으로 날짜 선택.
- 메시지 시각은 서버 저장 여부(UTC)와 무관하게 브라우저 로케일의 로컬 시간으로 표시.
- 새 메시지 도착/삭제/날짜 전환 시 대화창 최하단으로 자동 스크롤.

### 화면 구성 차등(강사 vs 수강생)
- 강사 화면 사이드 패널: 수강생 접속 주소(서버 LAN IP) 안내 + 접속 사용자 목록. 사용자 접속/퇴장 시 목록 실시간 갱신 + 시스템 메시지(입퇴장 알림)가 강사 대화창에만 표시.
- 수강생 화면 사이드 패널: 사용자 목록 대신 공유 디렉토리 파일 다운로드 목록 + 메시지 전송 대상(전체/강사) 선택.
- 수강생 접속 시 본인 대화창에는 입퇴장 등 시스템 메시지가 전혀 노출되지 않음(빈 상태로 시작).

### 대화 저장/내보내기
- 모든 메시지는 서버 파일로 영속 저장(날짜별).
- 이미지/첨부파일은 메시지 저장 폴더 하위 별도 폴더에 파일로 저장, 메시지 본문엔 경로/링크만 기록. 저장 파일명은 "원본이름.해시.확장자" 형태로 원본 파일명을 알아볼 수 있게 유지.
- 사용자는 선택한 날짜의 전체 대화를 Markdown 파일로 다운로드 가능.

## 비기능 요구사항

**성능:** 동시 접속자 약 30명 기준 실시간 메시지 지연 체감 없이(1초 이내) 송수신.
**보안:** 관리자/수강생 패스워드 기반 접속 통제, 패스워드는 환경변수로만 주입(코드/파일에 평문 저장 금지). 사용자 개인정보(닉네임/식별자)는 서버 비영속 저장. 파일 공유 디렉토리는 관리자가 지정한 경로 및 하위 경로로 한정(경로 탈출 방지). 메시지 삭제는 본인 것만 가능.
**확장성:** 동시 접속자 약 30명 지원.
**용량 제한:** 이미지/파일 첨부는 1건당 최대 10MB.
